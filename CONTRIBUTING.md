# Contributing

Create a focused branch, add or update tests, and run `ruff check .`, `ruff format --check .`, `mypy
src`, and `pytest` before opening a pull request. Keep infrastructure SDKs behind adapters and avoid
placing business policy in FastAPI routes or Streamlit components.

New knowledge sources require a clear author/publisher, a verified reuse license, an exact HTTPS URL,
an attribution URL, focused tags, and at least one evaluation case. Do not add unauthorized copies of
commercial filmmaking books.
